Logistic Regression

Binary Classification

Linear Regression predicts numbers.

But what about YES or NO?

A line outputs -∞ to +∞. We need output between 0 and 1.

The Sigmoid

σ(x) = 1 / (1 + e−(β₁x + β₀))
P < 50% → NOT obese
P > 50% → OBESE

How does it learn?

The dataset has the answers: weight + obese or not. The model scores itself.

Dataset (answer key)
weight: 35g → obese
weight: 18g → not obese
Model scores itself
35g obese → model: 90% ✅ 0.9
18g not → model: 5% ✅ 0.95
32g obese → model: 20% ❌ 0.2
Likelihood = model's grade
0.9 × 0.95 × 0.2 × ...
= 0.171
One bad prediction drags
the whole grade down

Why keep training?
After 2,000 iterations the model already gets 100% accuracy.

More iterations don't change the results — they increase confidence.
