# **Template Renderer**

---

## Overview

Build Render Template where the same temple can be render in HTML, PDF or CSV.

---

## Tech Stack

- **Language** -> Scala 3
- **Build Tool** -> sbt
- **Testing** -> ScalaTest 3.2.16
- **JDK** -> 25
- **PDF** -> iText 9

---

## Setup Instructions

### 1 - Clone

```bash
git clone https://github.com/rbleggi/tech-pocs.git
cd scala-3/template-renderer
```

### 2 - Build

```bash
sbt compile
```

### 3 - Test

```bash
sbt test
```
