# **Validation Framework**

## Overview

Build a validation Framework based on Annotations.

---

## Tech Stack

- **Java 25** → Custom annotations, reflection, records
- **Gradle** → Build and dependency management
- **JUnit 5** → Unit testing

---

## Setup Instructions

### 1 - Clone the Repository
```bash
git clone https://github.com/rbleggi/tech-pocs.git
cd java/validation-framework
```

### 2 - Compile and Run
```bash
./gradlew build run
```

### 3 - Run Tests
```bash
./gradlew test
```
